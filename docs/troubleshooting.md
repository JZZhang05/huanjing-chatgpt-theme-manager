# 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 安装器提示没有兼容的官方客户端 | 确认安装新版官方 Windows x64 ChatGPT。不要把其他程序改名为 ChatGPT.exe。 |
| 打开 ChatGPT 后没有「幻景」按钮 | 启用 Windows 的“幻景主题管理器”启动项；运行“修复主题启动.cmd”。应用更新期间请等待更新完成。 |
| 首次应用主题需要重开窗口 | 助手需要通过本机调试连接接入。先完成正在进行的操作，再允许应用正常关闭并重开。 |
| Steam 链接导入失败 | 确认已安装并登录 Steam、拥有 Wallpaper Engine、作品有权访问且已下载完整。 |
| 首次导入工具准备失败 | 检查网络能否连接 PyPI 后重试。原有壁纸和静态图不受影响。 |
| 图片盖住文字 | 降低面板透明度、提高背景遮罩，或选择自动文字颜色。 |
| 动态壁纸占用较高 | 试用静态插画；视频隐藏时会暂停，切换后会释放旧背景资源。 |
| 宠物旁边仍出现大块背景 | 更新到 1.0.3 以上版本并运行修复入口；新版本会清理透明辅助窗口上的旧主题。 |
| 恢复原生外观 | 选择“系统默认 · GPT 原生外观”。 |

反馈问题时请提供 Windows 版本、官方应用版本、管理器版本、现象和复现步骤。
截图请裁掉账号、聊天内容、文件路径等个人信息。不要上传整个安装目录、state.json、resolved-app.json、import-settings.json 或原始聊天日志。

本机安装目录内的 verification.json、startup-health.json 等文件用于诊断。
如需提供其中片段，请先删除用户名、路径、进程标识与会话信息。
