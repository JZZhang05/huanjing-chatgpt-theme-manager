# 幻景 · 使用说明

版本 1.1.0 · 公开发行版 · 2026-10-24

## 安装与启用

需要 Windows 10/11 x64、.NET Framework 4.8，以及已安装并登录的新版官方 ChatGPT Windows 客户端。
已验证客户端 26.1016.8622.0。内部包名为 OpenAI.Codex_2p2nqsd0c76g0，主程序为 ChatGPT.exe。
旧版独立 ChatGPT 客户端、网页、macOS、Linux、手机和 ARM64 未适配。

官方下载说明：https://learn.chatgpt.com/docs/windows/windows-app

从 GitHub Releases 下载 Huanjing-Setup-1.1.0.exe，双击安装到独立目录，例如 D:\Huanjing。
默认目录位于当前用户的本地应用目录。通常不需要管理员权限；Node.js、Python 已随包提供。
保持“自动随 ChatGPT 启用主题”勾选；首次接入可能需要应用正常关闭并重开，请先完成正在进行的操作。

安装后右下角出现“◈ 幻景”。以后照常打开官方客户端，后台助手会连接。
如果 Windows 禁用了“幻景主题管理器”启动项，请在系统启动设置中启用，或使用桌面入口手动启动。

## 壁纸与推荐配色

公开版内置一张生成的爱蜜莉雅静态插画，可离线使用。第三方 Steam 壁纸需由你自行订阅导入。
打开“幻景 → 选择壁纸”，选择条目，再点击“应用推荐配色”。

可以分别调整界面主色、强调色、文字颜色、面板透明度、背景遮罩和模糊。每张壁纸单独保存，拖动滑块即时预览。
面板透明度越高，顶部、侧栏、输入框和右侧面板越通透；背景遮罩越高，图片越柔和。
正文不清楚时，先降低面板透明度或提高遮罩；文字颜色可选择自动。
按钮会自动调整明暗、选择黑白图标，保持操作状态可辨认。

“系统默认 · GPT 原生外观”恢复官方原生样式，主题入口仍保留，可随时切回壁纸。
本工具没有开场动画。虚拟宠物、独立辅助窗口使用原生显示，不加载主题背景。

## 导入 Steam 壁纸

打开“＋ 导入 Steam 壁纸链接”，粘贴 Wallpaper Engine 创意工坊链接，例如：

https://steamcommunity.com/sharedfiles/filedetails/?id=3068152966

支持一次提交 1–10 个链接，可以勾选导入后切换并应用推荐配色。
导入需要本机 Steam、Wallpaper Engine 和作品访问权限。优先读取已下载作品；下载不可用时，请先在 Steam 订阅并等待下载完成。
作品可能因权限、网络或类型而无法导入。

首次转换会从 PyPI 下载约 30 MB 的固定版本编码工具，核对 SHA-256 后使用；失败不会影响已经导入的壁纸。
视频生成最长 120 秒的高清静音循环；场景、网页壁纸从独立 Wallpaper Engine 窗口生成约 20 秒循环。
只捕获该壁纸窗口，不录制鼠标。转换期间不要关闭或调整壁纸预览窗口尺寸。可关闭导入对话框继续聊天，任务仍在后台进行。
程序型壁纸不支持。

## 删除与恢复

每个壁纸条目都有“删除”。删除会隐藏列表项；正在使用的壁纸被删除后，界面切换到系统默认。
可以撤销，从“已删除的壁纸”恢复，或再次导入同一链接。媒体文件和配色仍保留，删除列表项不会立即释放磁盘空间。

## 升级与迁移

升级时选择原安装目录。安装器保留壁纸、导入列表和调色记录，并备份设置。
旧版本使用的 D:\EmiliaTheme 目录不需要改名；内部升级标识也保留，方便迁移。
公开版不包含工坊视频；已有目录中的动态爱蜜莉雅、蕾姆和其他壁纸继续可用。

换电脑时，在新电脑安装官方 ChatGPT 后运行安装包。只复制个人需要的壁纸与配置，再运行“安装并启用.cmd”重新识别本机环境。
不要将账号、运行日志和整套旧状态目录发给其他用户。

官方客户端更新后会重新识别已注册的安装位置并重试连接。未来界面或接入方式改变时，可能仍需更新管理器。
没有主题入口时，运行“修复主题启动.cmd”，或开始菜单“幻景主题管理器 → 修复连接”。

## 恢复与卸载

恢复原生外观：主题菜单中选择“系统默认”，或运行“恢复系统默认.cmd”。
卸载：Windows“已安装的应用 → 幻景 · ChatGPT 主题管理器”，或安装目录“卸载主题.cmd”。
卸载会移除主题程序和启动入口，保留壁纸与个人调色；官方客户端与聊天记录不受影响。
若要结束本次应用的调试连接，请卸载后正常退出，再从官方入口启动 ChatGPT。

安装包尚未进行代码签名，可通过 SHA256SUMS.txt 核对下载完整性，并查看随包源码。无需关闭系统安全功能。
本工具通过本机调试连接修改样式，安全与隐私范围见仓库 SECURITY.md、PRIVACY.md。
