幻景的首个公开源码版本，适用于新版官方 ChatGPT Windows x64 客户端。

- 在应用内管理壁纸，导入 Wallpaper Engine Steam 链接。
- 生成推荐配色，独立调节颜色、透明度、遮罩与模糊。
- 发送按钮、设置和个人中心跟随配色，保留宠物浮窗的原生透明效果。
- 限制媒体缓存、释放切走的背景资源，并减少状态文件重复写入。
- 自带运行环境，无需另外安装 Node.js 或 Python。

下载 Huanjing-Setup-1.1.0.exe 并安装到独立目录。可使用 SHA256SUMS.txt 核对文件。
公开版包含生成的静态插画；第三方工坊作品请自行订阅、导入。已有安装升级时保留本地壁纸和设置。

要求 Windows 10/11 x64、.NET Framework 4.8、新版官方 ChatGPT。
已验证客户端 26.1016.8622.0；旧版独立客户端、网页版和其他系统尚未适配。
导入新壁纸需本机 Steam、Wallpaper Engine 和作品访问权限。

这是非官方工具，接入会启用仅监听本机的调试连接；首次使用前请阅读 README、安全与隐私说明。安装包尚未进行代码签名。
